# AI vs ML vs Deep Learning

A simple comparison of Artificial Intelligence, Machine Learning and Deep Learning using definitions, differences and real-world examples. Built as Task 10 of the AI & ML Internship at Veda Technology.

## Objective
Build a clear understanding of the relationship between AI, ML and Deep Learning.

## What's Inside
1. Definitions of AI, ML and Deep Learning
2. Comparison table (scope, goal, data needed, feature engineering, compute, interpretability, algorithms)
3. Real-world examples of each
4. Short explanation of how they are related

## How They Are Related
AI is the broader field, ML is a subset of AI, and Deep Learning is a subset of ML.

**AI ⊃ Machine Learning ⊃ Deep Learning**

## Real-World Examples
| Field | Examples |
|---|---|
| AI | Chess engines, voice assistants, rule-based chatbots |
| ML | Spam filter, recommendation systems, house price prediction |
| Deep Learning | Image recognition, speech recognition, face unlock, language models |

## Files
- `AI_vs_ML_vs_DL.ipynb`: notebook with the complete comparison
- `README.md`: project overview

## Tools Used
Python, Jupyter Notebook, Markdown

## Key Learnings
- AI is the goal, ML is a way to achieve it, and Deep Learning is a powerful ML technique
- Deep Learning needs more data and compute but learns features automatically
- The right approach depends on the problem and the data available
